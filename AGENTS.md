# Working on these skills

These skills help a coding agent turn someone's references and feedback into a game with a coherent artistic direction.

- Keep the instructions focused on that creative process. Assume the agent already knows ordinary coding, API operations and error handling. Budget management belongs outside the skills.
- Describe concrete results: candidate assets, a running taste-pass interface, an implemented revision or an updated art bible.
- Keep the package standalone and flexible. Use the project's existing tools and conventions; templates and examples are optional.
- Keep it skills-only. Application code belongs in the user's project. Put each skill's supporting resources inside its folder so it works independently.
- For substantial changes, exercise a realistic task and inspect the result. Interface-building instructions need a working interface, not just a written plan.
