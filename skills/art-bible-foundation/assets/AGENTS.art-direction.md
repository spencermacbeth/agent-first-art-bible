## Art direction

Read `art-bible/README.md` and the relevant linked guidance before creating or
changing art, writing, interface, music or sound. Use the chosen references and
preserve the properties the user has already settled.

Use drawings, photographs, recordings and other supplied references to guide
new work. Keep experiments separate from the current direction. For broad
exploration, show meaningfully different alternatives before narrowing in.

When asked for a taste pass, build or update the review interface, load the
actual candidates, run it and provide a working link. Make the feedback
available to the next agent session. When asked to iterate, apply the feedback
and return the updated pass, keeping previous versions and notes.

Record chosen examples, useful production recipes and remaining questions in
the bible. Inspect integrated work in the game as well as in isolation.
