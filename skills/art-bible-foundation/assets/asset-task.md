# Asset task

## Question and role

What does this asset do in the game, and which artistic or technical question should this pass resolve?

## Authority and inputs

- Bible revision: the commit hash or dated snapshot this task reads from
- Bible section:
- Accepted reference IDs and original media:
- Current asset, if this is a revision:

## Fixed properties and exploration axes

The properties already accepted, the properties that may change, and the technical constraints that apply to every candidate.

## Generation access and budget

Permitted provider/model choices, credential environment-variable names, authorized total cost and batch bounds, and the authorization already given. With no paid generation authorized, the pass ends at briefs and estimates.

## Output location

The `reviews/<pass>/` directory for this task's candidates, derivatives, records and feedback. Nothing in it is current direction until a decision links it from the bible.

## Review target

Media types, intended display or playback conditions, renderer or runtime scene, target device if relevant, and where feedback will be kept.

## Completion and remaining decisions

The artifacts and evidence that answer the question. Candidate generation, technical checks and the owner's acceptance are three separate things; name each.
