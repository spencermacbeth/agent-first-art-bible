# Asset task

## Question and role

What does this asset do in the game, and which artistic or technical question should this pass resolve?

## Authority and inputs

Link the active bible section, accepted reference IDs, relevant original media and the current asset if this is a revision.

## Fixed properties and exploration axes

Name the properties already accepted and the properties that may change. State technical constraints that apply to every candidate.

## Generation access and budget

Identify the permitted provider/model choices, credential environment-variable names, authorized total cost and batch bounds. Record existing permissions. If no paid generation is authorized, prepare briefs and estimates without submitting.

## Review target

Specify media types, intended display or playback conditions, renderer or runtime scene, target device if relevant, and where feedback will be retained.

## Completion and remaining decisions

State the artifact and evidence needed to answer this task. Separate candidate generation, technical checks and the owner's acceptance. Use concrete paths and dependencies rather than human-time estimates.
