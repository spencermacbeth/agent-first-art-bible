# Taste-pass brief

Use this when the request is not already clear from the conversation and project. Keep only the fields this pass needs.

## What are we exploring?

The subject, what it does in the game and what the user wants to decide.

## References and existing choices

Links to the drawings, photos, recordings, example assets and relevant bible guidance. What should each reference contribute? What has already been chosen and must stay fixed?

## Alternatives to make

The properties to vary, candidate directions or model comparisons. For a first exploration, make the differences substantial enough to reveal new possibilities.

## Review experience

Where the user will see or hear the results, the controls they need, and how feedback gets back to the agent. Include relevant gameplay context, render conditions or target device. Use the project's current review tools when they fit.

## Deliver

The candidate files and working review link, or the narrower result the user requested. Record what remains for the user to choose and what the next iteration should preserve.
