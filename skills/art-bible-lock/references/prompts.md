# Iterating and retaining choices

## Refine a specific property

```text
Read my feedback in {location} alongside the candidates I reviewed. Keep
{chosen properties} and change {unresolved properties}. Work out whether the
change belongs in the source art, model, scene, sound or review presentation,
then implement it. Preserve the earlier versions and notes, add the revisions
to the taste pass and run it again so I can compare the result.
```

## Record the accepted direction

```text
Update {bible section} with the direction I chose in {feedback}. Link the actual
examples, describe what to preserve and avoid, and keep the useful generation
or rendering recipe. Leave unresolved parts open. Retain earlier directions
with the reason they changed, and check that the project's normal instructions
lead a new agent to the current examples.
```

## Turn a play session into tasks

```text
Read {recording or timestamped transcript} from my playthrough of {build}.
Turn my observations into follow-up tasks linked to the relevant moments.
Preserve what I experienced and investigate the cause before choosing a fix.
Implement the changes I requested within this task's scope. If feedback changes
the shared art direction, update the bible; otherwise keep the fix with the
relevant task. Tell me what to play again to check how the changes fit together.
```
