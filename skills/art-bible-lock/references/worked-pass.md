# Example: finding a save-point terminal

A fictional exploration game needs a save-point terminal that reads clearly from a fixed elevated camera. The developer provides a sketch of a hanging bracket and a photograph of weathered stone. The sketch contributes suspension and proportion; the photo contributes surface wear.

## First taste pass

The agent generates three concepts with different structures:

| Candidate | Direction |
| --- | --- |
| Suspended instrument | An asymmetric bracket holding a painted-metal body |
| Stone archive marker | A low monolith with a recessed face |
| Fabric signal post | A flexible canopy with exposed ribs and translucent panels |

It builds a local gallery showing the concepts at the intended on-screen size, with the references beside them. Each has space for notes. The developer opens the app and writes:

> Keep the suspended silhouette. The polished metal is wrong. Try a matte finish using the broad wear from my stone photo, without making the object look carved from stone. Leave the hanging proportions alone.

## Next taste pass

The agent reads the saved feedback, keeps the bracket and proportions, and makes a matte version. It adds that version alongside the original in the same gallery and returns the link. The developer can compare the result without losing the earlier notes.

If the developer likes the finish, the agent updates the terminal's bible entry:

> Use the suspended design and matte, worn-metal finish in the selected concept. Preserve its asymmetric bracket and hanging proportions. Use the sketch for structure and the stone photo for broad wear, not for a carved-stone material. The 3D interpretation and appearance through the game camera still need a pass.

The entry links the selected image, references and useful generation settings. Future agents can see both the choice and the examples that explain it.

## In the game

The agent uses the selected concept to guide a model, loads it in a viewer and then places it in the game. The developer checks whether the silhouette still reads from the gameplay camera and whether the terminal feels like part of the world. Those observations drive the next revision.

This example describes the workflow; it contains no generated media or claimed test results.
