# Building a taste pass

## Build the taste pass

```text
Build and run a local taste-pass interface for {candidate location}. Use the
project's existing stack where it fits. I need to compare {media types}, inspect
them properly, see the relevant references and leave notes about what to keep
or change. Make the notes available to you for the next iteration, using local
file persistence or a feedback export. Keep previous rounds and feedback.
Open the app, verify the actual media and feedback controls, and give me the
working link with a short explanation of how to return my feedback.
```

## Inspect the runtime

```text
Put {candidates} in {game scene or playback event} so I can judge them with the
real camera, lighting, interface and surrounding sound. Use our existing device
connection if that access is authorized, preserving saves and other sessions.
Capture what actually runs and record the build and asset versions. Tell me
what you observed and what I still need to play or listen to myself. Return a
working review or playable build, not just a description of the checks.
```
